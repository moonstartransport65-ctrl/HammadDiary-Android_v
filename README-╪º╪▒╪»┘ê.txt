حماد احمد بٹ کی ڈائری - اینڈرائڈ ایپ کا پروجیکٹ
=====================================

اس فولڈر میں ایپ مکمل تیار ہے۔ بس اسے APK میں بدلنا ہے۔ دو طریقے ہیں۔

طریقہ 1: اینڈرائڈ اسٹوڈیو (کمپیوٹر پر)
--------------------------------------
1. developer.android.com/studio سے Android Studio مفت ڈاؤن لوڈ کر کے انسٹال کریں۔
2. اس زپ کو کھولیں۔ Android Studio میں File > Open دبائیں اور فولڈر HammadDiary چنیں۔
3. پہلی بار Gradle sync ہو گا۔ انٹرنیٹ چاہیے اور دس پندرہ منٹ لگ سکتے ہیں۔ انتظار کریں۔
4. Build > Build Bundle(s) / APK(s) > Build APK(s) دبائیں۔
5. APK یہاں ملے گی: app/build/outputs/apk/debug/app-debug.apk
6. یہ فائل فون میں بھیج کر کھولیں۔ "نامعلوم ذرائع سے انسٹال" کی اجازت دے دیں۔

طریقہ 2: گٹ ہب سے (کچھ انسٹال کیے بغیر)
---------------------------------------
1. github.com پر مفت اکاؤنٹ بنائیں اور نئی repository بنائیں۔
2. اس فولڈر کی ساری فائلیں Add file > Upload files سے اپلوڈ کریں۔
3. اگر .github فولڈر اپلوڈ نہ ہو تو Add file > Create new file دبائیں، نام
   .github/workflows/build-apk.yml لکھیں اور فائل build-apk.yml کا سارا متن اس میں ڈال دیں۔
4. اوپر Actions ٹیب میں جا کر Build APK چنیں اور Run workflow دبائیں۔
5. پانچ منٹ بعد مکمل ہونے پر نیچے Artifacts میں hammad-diary-apk ڈاؤن لوڈ کریں۔
   اس زپ کے اندر app-debug.apk ہے۔

اہم باتیں
---------
- آواز فون کی اپنی انگلش آواز (Google Text-to-speech) سے آتی ہے۔ فون کی Settings میں
  Text-to-speech میں English (India) آواز انسٹال ہونی چاہیے۔
- فونٹس پہلی بار انٹرنیٹ سے آتے ہیں۔ انٹرنیٹ نہ ہو تو فون کا اپنا فونٹ چلتا ہے۔
- بچے کی اپنی MP3 آواز ایپ کے نیچے "آواز (MP3) شامل کریں" سے شامل ہوتی ہے۔

پلے اسٹور پر ڈالنے کے لیے
-------------------------
1. Google Play Console کا ڈویلپر اکاؤنٹ بنائیں (ایک بار 25 ڈالر فیس)۔
2. ایپ کی سائنڈ ریلیز فائل (AAB) بنائیں۔ Android Studio میں Build > Generate Signed Bundle / APK۔
   اپنی key فائل اور پاس ورڈ سنبھال کر رکھیں۔
3. آئیکن، اسکرین شاٹس، تفصیل اور پرائیویسی پالیسی کا لنک دیں۔
4. چونکہ ایپ بچوں کے لیے ہے، Families پالیسی کے سوالات بھریں۔

آواز ایپ کے اندر شامل کرنا
---------------------------
فون کی ٹیکسٹ ٹو اسپیچ پر انحصار نہ کرنا ہو تو آواز کی فائلیں ایپ کے اندر ہی رکھ سکتے ہیں۔
1. A سے Z اور 1 سے 100 تک کی آواز MP3 فائلوں میں تیار کریں۔ بچے کی آواز ریکارڈ کی جا سکتی ہے،
   یا کسی ٹیکسٹ ٹو اسپیچ ویب سائٹ سے بنا سکتے ہیں۔ ویب سائٹ کی استعمال کی شرائط ضرور دیکھ لیں۔
2. فائلوں کے نام ایسے رکھیں: A.mp3, B.mp3 ... Z.mp3 اور 1.mp3 ... 100.mp3۔
   پورا نام اس فولڈر میں ہے: app/src/main/assets/audio/NAMES.txt
3. فائلیں اسی فولڈر app/src/main/assets/audio/ میں ڈالیں۔
4. دوبارہ APK بنائیں (اوپر والا طریقہ)۔ ایپ پہلے یہ فائلیں چلائے گی، نہ ملیں تو فون کی آواز۔
   ایک سو چھبیس چھوٹی فائلوں کا سائز چند MB ہی ہو گا۔

رنگوں کے نام کی آواز: C_RED.mp3، C_ORANGE.mp3، C_YELLOW.mp3، C_GREEN.mp3، C_BLUE.mp3، C_PURPLE.mp3،
C_PINK.mp3، C_BROWN.mp3 بھی اسی audio فولڈر میں رکھ سکتے ہیں۔ نہ ہوں تو فون کی آواز چلے گی۔
